# ndma

AI-Integrated Digital Twin command dashboard for NDMA.

- `NDMA_Digital_Twin_Proposal.pdf` / `.docx` — solution proposal
- `NDMA_Digital_Twin_Tracker.xlsx` — project tracker built from the proposal (Tracker, Summary, Decisions & Dependencies, Risks, Holidays)
- `tools/build_tracker.py` — regenerates the tracker: `python3 tools/build_tracker.py NDMA_Digital_Twin_Tracker.xlsx`
